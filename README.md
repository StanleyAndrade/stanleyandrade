## 👋 About Me

I'm a **Full Stack Developer with 5 years of experience** building web applications and SaaS products for real clients. My foundation is on the **backend** (Node.js, Express, Fastify, MongoDB), and I also ship **frontend and mobile** with React, TypeScript, React Native and Flutter.

I'm used to **owning projects end to end** — gathering requirements, designing the system, writing the code, setting up servers and keeping things running in production.

- 🎯 **Currently looking for:** Java Intern / Junior Developer positions (remote or hybrid)
- 🎓 **Studying:** B.Sc. in Software Engineering at Unicesumar (expected 2029)
- 🌱 **Learning:** Java ecosystem and improving my spoken English
- 🗣️ **Languages:** Portuguese (native) · English (intermediate)
